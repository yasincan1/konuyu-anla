# Konuyu Anla

Türkçe, konu odaklı sınav çalışma sitesi. İlk tamamlanan ders **Bulut Bilişim**.

- 65 özgün soru/seçenek varyantı ve 325 çözümlü üretilmiş alıştırma.
- Kaynak fotoğrafı, konu anlatımı, adım adım çözüm ve şık analizi.
- Arama, soru gezinmesi, kişisel notlar ve tarayıcıda ilerleme kaydı.
- JSON yedek indirme ve geri yükleme.
- İki okunamayan kaynak kaydı envanterde ayrıca belirtilir.

`index.html` doğrudan açılabilir. Derleme veya paket kurulumu gerekmez.
GitHub Pages için `main` dalının kök dizini yayın kaynağıdır.

Notlar ve cevaplar ziyaretçinin tarayıcısında saklanır; bu depoya gönderilmez.
Yerel dosyadaki kayıtları canlı siteye taşımak için yerelden yedek indirip
canlı sitede geri yüklemek gerekir.

Diğer derslerin kaynakları envanterdedir; ayrıntılı çalışma içerikleri sonraki aşamadadır.
Kaynak eşleştirmeleri: `envanter.json`. Kontrol raporu: `dogrulama.json`.
Fotoğraflardaki işaretler resmî cevap anahtarı kabul edilmez; belirsizlikler soru sayfalarında belirtilir.
